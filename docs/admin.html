依頼受付設定

各依頼の受付状態を変更できます。受付停止中にすると、依頼フォームから選択できなくなり、API側でも新規依頼を拒否します。 また、そのサービスを含むセット料金も自動的に受付停止になります。
セット料金との連動 MIX停止 → MIX+MV / MIX+MV+イラスト が停止 MV停止 → MIX+MV / MV+イラスト / MIX+MV+イラスト が停止 動画編集停止 → 動画+イラスト が停止 イラスト停止 → MV+イラスト / 動画+イラスト / MIX+MV+イラスト が停止 セット停止 → すべてのセット料金が停止
